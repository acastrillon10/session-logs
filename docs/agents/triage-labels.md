# Triage labels

The engineering skills use five canonical triage roles. This table maps each role to its label in this repository.

| Canonical role    | Tracker label      | Meaning                                  |
| ----------------- | ------------------ | ---------------------------------------- |
| `needs-triage`    | `needs-triage`     | A maintainer needs to evaluate the issue |
| `needs-info`      | `needs-info`       | Waiting for more details from the author |
| `ready-for-agent` | `ready-for-agent`  | Fully specified and ready for an agent   |
| `ready-for-human` | `ready-for-human`  | Requires human implementation            |
| `wontfix`         | `wontfix`          | Will not be acted on                      |

When a skill names a canonical role, use the matching tracker label from this table. Edit the second column if the repository adopts different label names.
