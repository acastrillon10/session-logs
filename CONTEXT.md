# Session logs

This project creates concise records of coding work for later recall and reporting.

## Language

**Session log**:
A scan-friendly Obsidian note that records the outcome and current state of work since the preceding session log for the same project. The person creates it manually from the active branch.
_Avoid_: Transcript, activity dump

**Git context**:
Repository facts used to support a session log, including commits, the current branch, and uncommitted changes.
_Avoid_: Agent context, conversation history

**Session summary**:
A short account of what the person accomplished, written manually or derived later from Git context. Creating a session log does not require an LLM.
_Avoid_: Commit list, transcript summary
